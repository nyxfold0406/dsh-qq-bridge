# 桌面待办 · 数据格式

> 这是随 `dsh-qq` 一起发布的小程序：一个独立的 Windows 桌面小窗（WinForms，
> 单个 exe，不需要 DSH 也能跑），数据全是**纯文本**，所以别的程序（比如 QQ 桥的
> `/日程` `/待办`）可以直接读。
>
> 跑起来：双击 `桌面待办.exe`。它在**自己所在的目录**找 `todos.txt` /
> `classes.txt` / `events.txt`，没有就当成空的。想让 QQ 桥读到它，把桥配置里的
> `todoAppDir` 指到同一个目录即可。
>
> 重新编译：`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe
> /win32icon:app.ico /resource:emblem.png,emblem.png TodoPet.cs`（改 exe 前先关窗口，
> 否则文件被占用；`更新待办.cmd` 就是干这个的）。

小窗本体是 `桌面待办.exe`（独立进程，开机需自己点快捷方式，DSH 关了它也在）。

它只认这两个纯文本文件，**改完 1 秒内自动刷新，不用重启**。别的 agent 直接改文件或调 `todo.py` 都行。

## todos.txt

每行一条，字段用 Tab 分隔，四段（旧的两段/三段格式仍可读）：

```
状态	截止时间	预计耗时(分钟)	紧要程度	文字
```

- 状态：`1` = 已完成，`0` = 未完成
- 截止时间：`YYYY-MM-DD HH:mm`，没有就留空
- 预计耗时：整数分钟，没有就留空
- 紧要程度：`S`/`A`/`B`/`C`/`D`/`E`，可空；S 最急、E 最缓
- 文字：单行，不能含 Tab / 换行

（只有 4 段的旧行仍然能读，按"没有紧要程度"处理。）

示例：

```
0		120		读两篇文献
0	2026-11-19 18:00	90	A	把实验图重画一遍
1	2026-11-18 21:00	30		跑通一遍分析流程
```

## classes.txt

每行一节，四段：

```
星期几	开始	结束	课名
```

- 星期几：`1`=周一 … `7`=周日
- 时间：`HH:MM`

示例：

```
1	08:00	09:40	系统解剖学
3	08:00	09:40	生物化学
5	14:00	15:40	医学统计
```

## events.txt（一次性的安排：会议 / 培训 / 临时课）

每行一条，六段（旧的前五段仍可读，按「日常」处理）：

```
日期	开始	结束	类型	名称	分类
```

```
2026-11-18	18:00	21:30	拍摄	校园活动拍摄	特殊
2026-11-21	08:15	09:45	考试	英语口试（带证件）	重要
2026-11-21	10:00	12:00	拍摄	活动素材剪辑	特殊
```

类型随便写（会议 / 培训 / 课 / 体检……），会显示成一个不可勾选的小标签。

**分类**只有三个值：`日常` / `特殊` / `重要`，留空按 `日常`。

- 日常：上课、例会这类常规事务（课程行自动标「日常」，不用写进文件）
- 特殊：拍摄、演出、临时安排这类非常规的
- 重要：考试、答辩、复试这类不能出错的

分类在「清单」和「日程」里显示成小色标（日常=蓝灰、特殊=琥珀、重要=红）；
**右键那条事务 → 归为「日常/特殊/重要」** 就能改；命令行 `py todo.py ev cat 2 重要`。

**课程（每周固定）走 classes.txt，一次性安排在 events.txt**。两者在「清单」里只显示今天的，
在「日程」里按点选的那天显示，和任务按时间合成一条线。它们都没有勾选框，勾不掉。

## archive.txt（归档）

格式与 `todos.txt` 相同。界面上「打勾 → 右键标题栏 → 归档已完成」会把这些条目从清单移到
`archive.txt`，不再占用清单空间；「查看归档…」里可以恢复或永久删除。

命令行：`py todo.py archive`（把所有已完成的归档）、`py todo.py arch list`、`py todo.py arch restore 2`。

## 日程怎么算

- 一天按 `08:00–23:00` 算 15 小时
- 空闲 = 15h − 当天课表总时长
- 当天任务耗时加总后与空闲相比：
  - 比例 ≤45% → **轻松**（绿）
  - ≤75% → **正常**（黄）
  - >75% → **紧张**（红）
  - 超过空闲 → **排不下**（红）

倒计时颜色：蓝（>7 天）、绿（≤7 天）、黄（今天/明天/≤3 天）、红（已过期）。

## todo.py

给人和别的 agent 的命令行入口（Windows 上 `py` 可用）：

```
py todo.py list
py todo.py add "读两篇文献" --due "2026-11-20 18:00" --min 90 --prio A
py todo.py done 2
py todo.py undo 2
py todo.py due 2 "2026-11-21 09:00"
py todo.py due 2 clear
py todo.py min 2 45
py todo.py edit 2 "新文字"
py todo.py del 2
py todo.py cls list
py todo.py cls add 3 08:00 09:40 生物化学
py todo.py cls del 1
py todo.py ev list
py todo.py ev add 2026-11-21 14:00 15:00 会议 选题讨论 重要
py todo.py ev cat 2 重要
py todo.py ev del 1
```

序号就是 `list` 里显示的序号。

## 其它

- `cfg.txt`：窗口位置、尺寸、是否收起、当前页；程序自己读写，别手改
- 写文件用"先写 .tmp 再替换"，避免读到半截
- 小窗自己写盘只在用户点按时发生（勾选/加条/改条目），外部写入后它会先重载再写回
