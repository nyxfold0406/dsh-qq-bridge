# 重启后的回归清单

改完插件要重启 DSH 才生效（宿主插件没有热更新）。下面每一条都在 QQ 上做，做完打勾。
**挂一条就回滚**：把改动前的备份目录覆盖回来，再重启一次。

## 必测（缺一条都不算过）

1. **活着**：重启后发一句「在吗」，桥要回。
2. **普通对话**：回复要回到同一个 QQ，不是发去别的会话；回复里不该出现
   Markdown 的 `**`、`#`。
3. **长回复分段**：让它给一段超过 `maxChars` 的内容，应该分几条发出来。
4. **/任务**：发 `/任务`，回一张各会话快照，不唤醒会话。
5. **审批**：触发一次需要审批的动作，QQ 上应收到审批转发；回「允许」后继续，
   回「拒绝」后停。
6. **发文件**：`qq_send_file` 发一个小文件能到手机；发 `.credentials.yaml`
   必须被拦。

## 按需测

7. **语音**：手机发一条语音，转成文字进会话（需要 `pythonPath` 里装了 faster-whisper）。
8. **图片**：发一张图，会话能看到；扩展名和真实内容不一致的图也别报错。
9. **群聊**：在允许的群里 @ 它，回一句；连发 5 条，限流生效。
10. **挂断/接线**：`挂了` 回到总机，`接 N` 接回指定会话。
11. **NapCat 掉线**：关掉 NapCat，`qq_status` 要显示不可达且不崩；开回来
    60 秒内自动恢复（日志里有 `napcat back online`）。

## 出问题怎么报

把「哪条没过、报错原文、当时 `last-error.txt` 的内容」一起贴出来。只说「不行」
没法定位。
